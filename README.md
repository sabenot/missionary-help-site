# 오지선교 도움 연결 (v3.3 · JuYeong 작업본)

접근이 어려운 개신교 선교 현장을 위한 정보 안내 단일 페이지 초안입니다. 현장 준비 분야, 자료실(공식 안내·과거 사례), 공식 창구를 한 페이지에 모았습니다. 서버 없이 브라우저에서만 동작하며, 개인정보를 받지 않습니다.

## 여는 방법
- `index.html`을 브라우저로 바로 열거나
- 이 폴더에서 `python3 -m http.server 8000` 실행 후 http://localhost:8000

## 파일
- `index.html` 페이지 · `styles.css` 스타일 · `app.js` 검색/필터
- `resources.json` 자료 원본 (`data.js`는 같은 내용을 file://에서도 읽히게 담은 사본 — 자료 수정 시 둘 다 갱신)
- `collection.html` 오프라인 자료 목록
- `country-philippines.html` 나라별 안내 1호(필리핀). 외부 스크립트·폰트 없는 한 파일이라 저장·인쇄로 오프라인 보관 가능
- `country-japan.html` 나라별 안내 2호(일본). 같은 구조의 한 파일
- `country-thailand.html` 나라별 안내 3호(태국). 같은 구조의 한 파일
- `country-kenya.html` 나라별 안내 4호(케냐). 같은 구조의 한 파일
- `country-cambodia.html` 나라별 안내 5호(캄보디아). 같은 구조의 한 파일
- `country-tanzania.html` 나라별 안내 6호(탄자니아). 같은 구조의 한 파일
- `country-indonesia.html` 나라별 안내 7호(인도네시아). 같은 구조의 한 파일
- `country-uganda.html` 나라별 안내 8호(우간다). 같은 구조의 한 파일
- `checklist-africa.html` 상황별 체크리스트 1호(동아프리카 출국 전, 케냐·탄자니아 공통). 인쇄용 한 파일, 체크 표시는 저장·전송하지 않음

앞으로 함께 내용과 디자인을 계속 다듬어 갈 작업본입니다.
