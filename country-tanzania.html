무비자 불가 — e-Visa 또는 도착비자

장기 선교: 거주허가 Class C-3 (Approved religious activities · missionaries)

탄자니아 이민청 거주허가 안내: 90일을 넘겨 머물려면 거주허가가 필요하고, Class C는 연구자·은퇴자·선교사·자원봉사자 등이 대상. C-3 ‘정부가 승인한 종교활동 종사자(선교사)’ 수수료 200달러(자원봉사 C-5도 200달러). Class B·C는 입국 전에 받아야 하고, 신청 주체는 원칙적으로 탄자니아에 등록된 기관이에요. 절차: 온라인 계정 생성 → 서류(모두 공증본) 첨부·제출 → 승인 통지 뒤 60일 안에 납부(넘기면 신청 자동 삭제) → 이민국에서 지문·사진 등록 → 약 1주 뒤 발급. 공통 서류: 기관 설명 서한, 노동청 취업허가(Work Permit) 또는 관계기관 면제서(선교사·자원봉사·NGO 직원), 여권 사본(6개월 이상), 사진, 이력서, 직무 설명, 학력 증명 공증본, 영어·스와힐리어가 아닌 서류 공식 번역, 기관(선교회) 등록증, 기관 정관의 서명·목적·회원 쪽. 선교사 추가 서류: 직무 설명, 해당 직종 면허(교사·의사·간호사·회계사 등), 사제 선교사는 안수증, 자원봉사 선교사는 봉사 계약서, 필요하면 현장 확인 보고서.

외국인고용규제법(CAP. 436, 2023 개정판)은 취업허가를 종류별로 나누고, Class D는 “등록된 종교·자선 활동에 고용되거나 종사하는 외국인”에게 발급한다고 정해요. 위 거주허가 안내는 선교사·자원봉사자에게 취업허가 대신 ‘면제서’도 받을 수 있다고 적어, 어느 쪽이 맞는지는 파송·현지 기관과 노동청에 확인해야 해요.
